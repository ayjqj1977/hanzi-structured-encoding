# 开放数据集：字形→语义 可训练判别器权重

本目录导出的 `model_for_web.json` 是一个**自包含、可复现**的开放数据集：
别人拿到这个 JSON，无需运行任何训练脚本，就能用纯前端/纯 Python 复现
"给定任意汉字 → 预测其《同义词词林》语义大类（及物类内部中类）"的预测结果。

## 文件清单

| 文件 | 作用 |
|---|---|
| `model_for_web.json` | **核心开放数据**：训练好的判别头权重 + 标准化统计量 + 逐字字形组件 + 词林大类名。自包含。 |
| `reproduce.py` | 免训练复现脚本：`python reproduce.py 树` 即可输出预测。 |
| `glyph_semantic_predictor.html` | 离线网页 demo（已内嵌同一份 JSON），打字出字即得预测，纯前端、零依赖。 |
| `train_discriminator.py` | 训练脚本（若想自己从头训出这份权重）。 |
| `train_multi_mid.py` | 跨大类内部中类判别扩展实验脚本。 |
| `dt_cmp.py` | 逻辑回归 vs 浅决策树对比脚本（验证几何特征是否因模型太浅被埋没）。 |

## model_for_web.json 字段说明（Schema）

```
labels         : [A,B,C,...]           11 个语义大类字母
da_lei         : {A:"人", B:"物", ...} 大类字母→中文名
W, b           : 大类判别头 权重(283×11) 与 偏置(11)   —— softmax 逻辑回归
n_rad, n_str   : 部首类别数(211) / 结构类别数(13)
rad_ms, str_ms, scnt_ms, s32_ms, det_ms : 各特征块的 [均值, 标准差]（z-score 标准化用）
rad_idx2rad    : 部首索引 → 部首字
str_idx2name   : 结构索引 → 结构名
char_comp      : { 字: {r, st, n, s32[26], det[32], lab} }  逐字原始字形组件
D              : 物(B)类内部 18 中类判别头 {mid_labels, mid_example, W(283×18), b(18)}
```

特征向量拼接顺序（283 维）：`部首 one-hot(211) + 结构 one-hot(13) + 笔画数(1) + s32(26) + det(32)`，
每个块用对应的 `*_ms` 做 z-score 标准化。预测：`softmax(feat · W + b)`。

## 复现（两种零训练方式）

1. 命令行：`python reproduce.py 狗`
2. 浏览器：双击 `glyph_semantic_predictor.html`，输入框打字。

## 训练（若想复现权重本身）

需要原始数据：`tree_data.json`、`stroke_features.json`、
`../neuroglyph34_project/struct32_aligned.json`、`cilin_index.json`、`cilin_extended.txt`。
然后 `python train_discriminator.py`（设置环境变量 BASE / BASE2 指向数据目录）。
本地 CPU、几秒到十几秒训完，无 torch、无云端。
