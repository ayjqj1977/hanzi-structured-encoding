# NeuroGlyph-34 云端训练速查

## 模型架构
NeuroGlyph34-Large: 5路CNN + 5路Embedding → 融合256维 → 8层Transformer → LM Head(7987)
参数量: ~15M (GPU友好)

## 数据
自动加载以下全部语料:
- corpus_combined.txt (286MB)
- corpus_knowledge_graph.txt (271MB)  
- corpus_training.txt + corpus_training_combined.txt
- 7_训练语料/ 所有JSON
- modern_text/ 目录下所有txt/json (自动下载现代语料)

## 云端运行
```bash
# 上传整个 neuroglyph34_project 目录到云端
# 然后:
pip install torch numpy
python train_neuroglyph34_cloud.py

# 自定义步数:
python train_neuroglyph34_cloud.py --steps 50000 --lr 2e-4

# 从断点恢复（自动检测）:
python train_neuroglyph34_cloud.py
# 或指定checkpoint:
python train_neuroglyph34_cloud.py --resume checkpoints_cloud/latest.pt
```

## Checkpoint说明
- 每5000步保存: checkpoints_cloud/step_5000.pt, step_10000.pt...
- 最佳模型: checkpoints_cloud/best.pt
- 最新状态: checkpoints_cloud/latest.pt（自动用于恢复）
- 只保留最近3个，避免磁盘爆炸
- 使用原子写入（先.tmp再rename），断电安全

## 补充现代语料
把任何中文txt/json文件放到 modern_text/ 目录即可自动加载。
推荐来源:
- THUCNews 子集 (搜"THUCNews 下载")
- Wikipedia中文提取
- 新闻语料 (搜"中文新闻语料 公开")
